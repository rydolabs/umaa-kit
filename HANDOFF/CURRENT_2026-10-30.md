## 2026-10-30 targeted supervisor change

Source files:
- `sdk/tools/umaa_operation_journal.py`
- `sdk/tools/umaa_process_supervisor.py`
- `sdk/tests/test_operation_journal_recovery.py`

Changes:
1. Reconciliation now acquires the same O_EXCL owner marker as a live
   supervisor for the *entire* read / reconcile / fsync / replacement
   transaction. Another supervisor cannot start between an unchecked
   existence read and a reconciliation write. No automatic stale-owner
   takeover is introduced.
2. Reject JSON boolean `true` as journal schema version 1.
3. An already quarantined, absent or exited worker cannot add a new
   durable Command intent before a guaranteed-failing IPC attempt.
   Validate integer action/session identities before admission.
4. Regression tests cover exclusive concurrent reconciliation, corrupted
   files and owner release, durable session deduplication, 24 bounded
   close/reopen cycles, and dead-worker admission. Tests require no DDS
   license or physical hardware.
